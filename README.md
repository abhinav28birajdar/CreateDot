## About

CreateDOT brings creative portfolios, community feedback, collaboration, jobs, and AI-assisted tools into one modern web app. It is designed to help creators present their work and connect with meaningful opportunities.

CreateDOT is created and managed exclusively by **[abhinav28birajdar](https://github.com/abhinav28birajdar)**.

## Technology

- **Next.js 15** with the App Router
- **React 19** and **TypeScript**
- **Tailwind CSS**, Radix UI, Lucide, and Framer Motion
- **Supabase** for PostgreSQL, authentication, storage, and realtime features
- **Google Gemini** for AI-powered creative features
- **Vercel** for deployment

## Getting started

```bash
npm install
cp .env.example .env.local
npm run dev
```

Set `NEXT_PUBLIC_SUPABASE_URL` and `NEXT_PUBLIC_SUPABASE_ANON_KEY` in `.env.local` before using data-backed features.
